# 单主题技术学习模板（AI 全自动版）

> 适用场景：一个目录只学习一个主题（例如仅学习 Raft）。

## 你只需要做两件事

1. 把学习资料放进当前目录（论文、笔记、链接说明都可以）。
2. 对 AI 说一句：`开始学习`（首次可说：`开始学习 Raft`）。

---

## 一键复制到新目录（四文件）

在模板目录执行：

```bash
TARGET_DIR="/path/to/your/new-study-dir"
mkdir -p "$TARGET_DIR"
cp AGENTS.md README.md SESSION-TEMPLATE.md STUDY-TRACKER-TEMPLATE.md "$TARGET_DIR"/
```

说明：
- 这条命令只复制 4 个核心文件。
- 进入新目录后，直接对 AI 说 `开始学习` 即可。

---

## AI 会自动做什么

每次你说 `开始学习`，AI 必须自动执行：

1. 读取 `progress/study-tracker.md`（若不存在则按模板自动创建）。
2. 读取最近一次会话记录（若当天文件不存在则自动创建当天会话文件）。
3. 若是首次学习，先让你确认主题和资料；学习边界与阶段目标由 AI 基于参考学习路线拟定草案并让你确认。
4. 根据追踪器中的「下一次学习入口」继续，不从头开始。
5. 自动确定今天要学的具体内容并开始苏格拉底教学。
6. 结束后自动更新会话记录与学习追踪器。
7. 同步更新本文件中的「学习主题与资料基线（AI 维护）」区块。

## 学习主题与资料基线（AI 维护）

> 首次学习建档后由 AI 填写；后续你新增资料或调整范围时由 AI 自动更新。

  2. 课程/书籍路线：无
  3. 社区友好实践路线：SOFAJRaft 工业级实现参考
- 适配说明：先理论后实践，论文打基础 → SOFAJRaft 对照实现细节

```text

├── AGENTS.md
├── README.md
├── SESSION-TEMPLATE.md
├── STUDY-TRACKER-TEMPLATE.md
├── progress/
│   └── study-tracker.md
└── sessions/
    └── YYYY-MM-DD/
        └── session-notes.md
```

---

## 使用原则

- 不需要手动把模板复制到 `sessions/` 或 `progress/`。
- 不需要你先写学习目标，AI 会基于进度自动生成本次目标。
- 新一天开始学习时，默认延续前一天进度。
- 只有当你明确说「重置/重学」时，AI 才能从头规划。
